# About Me & byrdsnest api client

Hi there! 👋 I'm [@byrdchermit](https://github.com/byrdchermit), the author and creator of **byrdsnest api client**.

---

## Why I Built byrdsnest api client

Working with APIs is part of my everyday life. Whether developing microservices, testing REST endpoints, validating webhook deliveries, or debugging third-party integrations, an API client is an indispensable tool in my toolbox.

However, I found myself increasingly frustrated with the direction standard desktop API clients were heading:
- **Heavyweight overhead**: Running an extra Chromium-based desktop client consuming gigabytes of RAM just to send an occasional `GET` or `POST` request felt unnecessary.
- **Forced cloud sign-ins & telemetry**: I wanted my API keys, environment credentials, and requests to stay strictly local on my machine.
- **Context switching**: Constantly jumping back and forth between VS Code and external apps broke my development flow.

I built **byrdsnest api client** to be the API client I always wanted: **fast, local-first, lightweight, and living directly inside Visual Studio Code.**

---

## What Makes byrdsnest api client Special

1. **Native VS Code Experience**: Sits right in your sidebar Activity Bar, uses your editor's native theme, and opens tabs right where you edit code.
2. **Crystal-Clear Inheritance**: Multi-layer variable and header cascading (Profile → Parent Environment → Environment → Collection → Folder → Request) with a visual inspector that shows you exactly where every value came from.
3. **True Local Privacy**: Zero telemetry, no cloud accounts, and zero tracking. Everything lives in your local workspace.
4. **Frictionless Migration**: Direct import and export for Postman collections, Postman environments, OpenAPI/Swagger specs, and full backup files.
